Frequently Asked Questions

How do I log a drink?

Open Today and tap one of the quick sizes in Quick Log. For more detail, tap More to add or edit a record.

How do I set or change reminders?

In Plan, set workdays, active hours, quiet hours, and reminder times. After you save, the app schedules local notifications for the next 7 days.

Why am I not receiving reminders?

Check that notification permission is enabled, the reminder slot is enabled, the time is inside active hours and outside quiet hours, and open the app once so the reminder plan can resync.

How do I edit or delete a record?

Tap a record in the Today timeline to edit volume, beverage, drinking time, or note. You can also delete it, and all progress, charts, and statistics update immediately.

How do I export my data?

In Data > Local Data Management, choose Export JSON or Export CSV. The file is shared through the system share sheet.

How do I clear all data?

In Data > Local Data Management, tap Clear All Data and confirm. This deletes local records, plan, and pending reminders. It cannot be undone.

How do I create an account?

Open Data, choose Create Account, enter a username, password, and matching verification password. Core features still work without an account.

How does sync work?

Guests use only local data. After you log in, the app asks how to handle any existing device data before syncing. When sync is on, local changes are pushed to the sync server and account changes can be pulled back.

How do I delete my account?

Open Data and tap Delete Account, then confirm. The account and all data synced to the server are deleted. Local device data remains unless you also clear it in Data > Local Data Management.

Do I need an account?

No. Core features do not require an account and work offline. An optional account is only for server-side backup and sync.
